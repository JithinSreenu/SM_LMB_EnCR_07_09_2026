Pedograph

Overview

Dual-channel waveform controller for the ESP32 load-cell simulator (DAC1 = heel, DAC2 = toe). The panel is the output: the preview graph shows the exact levels, and every control is mirrored to the connected ESP32 automatically. There is no separate demo mode.

Device connection

  • Select the ESP32 COM port and click Connect (115200 baud).
  • On connect, the full panel state is pushed to the device; every later change follows within a fraction of a second.
  • The Output Limits card shows the mirror state. Device responses appear in the terminal log.
  • Save stores the device config in ESP32 flash; Load recalls it.

Output ceiling

The Ceiling setting (0.50–3.30 V) clamps every value before display and before sending — amplitude, offsets, and gait Vmin/Vmax. The dashed line on the graph marks the ceiling.

Firmware notes

  • Custom waveform is a panel preview only — the ESP32 firmware holds a flat offset for it.
  • Phase is sent in degrees. Duty applies to Square/PWM only.
  • Raw firmware commands can still be typed in the terminal input (e.g. status, mon, csv).

Keyboard shortcuts

  • Space — Start / pause output
  • Escape — Stop output
  • Ctrl+1–9 — Presets (Walk through Test)
  • Ctrl+R — Reset counters
  • Ctrl+E — Export CSV
